# Changelog

All notable changes to CYTools are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Release dates correspond to the commit dates of the `vX.Y.Z` tags in this
repository; the corresponding entries on the
[GitHub releases page](https://github.com/LiamMcAllisterGroup/cytools/releases)
are occasionally published a day or two later.

## [Unreleased]

### Added

- `compute_gv` can compute Gopakumar-Vafa invariants for a set of target
  points ([#86](https://github.com/LiamMcAllisterGroup/cytools/pull/86)).
- Contributor process documentation (`CONTRIBUTING.md`) and this changelog.

### Changed

- Much faster secondary-subfan computation in the NTFE code.
- More neighbor-triangulation information is tracked by `Triangulation`.
- Direct dependencies are declared explicitly, and `uv` installs the test
  tools by default
  ([#73](https://github.com/LiamMcAllisterGroup/cytools/pull/73)).
- Ruff-driven lint and style fixes across the codebase, plus a follow-up
  bugfix for a change ruff applied automatically.
- Added a `.mailmap` so that author names are merged in the git log output
  (this does not change the recorded history).
- GitHub Actions dependency bumps
  ([#89](https://github.com/LiamMcAllisterGroup/cytools/pull/89)).

### Removed

- Dead, commented-out code in the F-theory subpackage (`FT_CY.py`,
  `Uplift_functions.py`), in `vector_config/fan.py`, and disabled `Fan` code.

## [1.4.12] - 2026-07-15

### Added

- F-theory subpackage `cytools.f_theory` (`FT_CY.py`, `Uplift_functions.py`)
  for F-theory uplifts
  ([#82](https://github.com/LiamMcAllisterGroup/cytools/pull/82)), and a
  `demos/` folder with an `f_theory_uplifts.ipynb` notebook
  ([#87](https://github.com/LiamMcAllisterGroup/cytools/pull/87)).
- HiGHS solver backend for cone operations, made the default; `highspy` is
  pinned to match the HiGHS version bundled by OR-Tools.
- Parallel computation of 2-face neighbor triangulations, and a toggle for
  `only_regular` on 2-face flips.

### Changed

- Installation reworked to be Docker-free: updated Linux and macOS install
  scripts, new uninstall scripts, and the Windows installer removed. Old
  Docker-era notes and install instructions were cleaned up.
- The 2-neighbor interface was cleaned up and `fine_neighbors_2d` made
  private, with callers routed through `neighbor_triangulations`.
- `osqp` pinned and the associated deprecation warnings fixed; minimum
  `regfans` version raised.
- Bare `except` clauses removed (they were also swallowing Ctrl-C).
- PEP 8 cleanup in `utils.py`
  ([#79](https://github.com/LiamMcAllisterGroup/cytools/pull/79)).

### Fixed

- Hodge number bug.
- Mapping an FRT of a point configuration to a fan.
- Broken update checker.

## [1.4.11] - 2026-06-12

### Added

- Opt-in uniform Calabi-Yau sampler, and a dualGNN-based sampler for
  O(100) sampling of NTFEs at high `h11` (optional `gnn` extra).
- Seed arguments for reproducible sampling.

### Changed

- Exhaustive NTFE construction sped up by orders of magnitude in some cases,
  by warm-starting the linear programs.
- Safer writing of zipped-pickle cache files.
- Hardened some constructors.

### Fixed

- Documentation-website generation bug.
- Clearer error message for a common constructor mistake.

## [1.4.10] - 2026-06-03

### Changed

- Faster kappa contractions, intersection numbers, and NTFE counting.
- Option to avoid copying kappa.
- `numba` import made explicit.
- `is_reflexive` updated.

### Fixed

- Missing dependency.

## [1.4.9] - 2026-05-04

### Added

- Codimension-2 and higher face enumeration for pointed cones; the cone face
  lattice was split from the facet computation
  ([#64](https://github.com/LiamMcAllisterGroup/cytools/pull/64)).

### Changed

- The external `normaliz` dependency for `hilbert_basis` was made explicit
  ([#70](https://github.com/LiamMcAllisterGroup/cytools/pull/70)).
- The Hodge number methods of `Polytope` default to `lattice="N"`.

### Fixed

- `Polytope.is_reflexive()` for translated reflexive polytopes
  ([#71](https://github.com/LiamMcAllisterGroup/cytools/pull/71)).
- Call-order dependence in `Fan.intersection_numbers()`
  ([#72](https://github.com/LiamMcAllisterGroup/cytools/pull/72)).
- A `ppl` rounding-mode issue.
- Handling of facets of 1D cones, and of 0D and -1D polytopes in `HPolytope`.

## [1.4.8] - 2026-04-12

### Added

- Preliminary polytope sampling in `fetch_polytopes`, including handling of
  `samples` larger than the number of available polytopes.
- `latticepts` used as the backend for polytope and small-cone lattice point
  enumeration, making it substantially quicker.

### Changed

- Adapted to the new `triangulumancer` API.
- Lazy construction of secondary cones.
- `max_deg` and `min_points` may be left as `None` in `compute_gv`
  ([#61](https://github.com/LiamMcAllisterGroup/cytools/pull/61)).
- Better `deterministic_glsm_basis` support.
- Polytopes of dimension <= 0 are allowed.
- Return types cleaned up and completed across several modules.

### Fixed

- Fetching of 5d reflexive polytopes.
- Row de-duplication that still allowed some duplicates.
- A cache that was being ignored, plus caching of the hash.

## [1.4.7] - 2026-03-08

### Added

- Flag to set the GLSM/divisor basis in a deterministic way, also honored
  under dualizing and Minkowski sums.

### Changed

- Faster second Chern class computation and better setting/tracking of the
  Gale basis.
- Assorted micro-optimizations; `defaultdict` avoided where possible.

## [1.4.6] - 2026-02-23

### Changed

- More `Cone` arguments exposed.
- Higher verbosity available for vector-configuration intersection number
  computations.
- `is_trilayer` generalized to non-4D polytopes
  ([#60](https://github.com/LiamMcAllisterGroup/cytools/pull/60)).
- `pplpy` listed in the environment files as well.
- Small stylistic changes
  ([#59](https://github.com/LiamMcAllisterGroup/cytools/pull/59)).

### Fixed

- Vector-configuration bugfixes.

### Removed

- Docker installation and the corresponding Docker CI test.

## [1.4.5] - 2026-01-20

### Added

- Vector configuration classes (`cytools.vector_config`).
- `cytools.ntfe` and `cytools.vector_config` exposed at the package level.
- Generators may be set in GV computations.
- Stretching option in `find_lattice_points`.
- `regfans` dependency.

### Changed

- Python 3.14 allowed.
- Triangulation constructors take keyword arguments only.
- Lattice points and degrees are returned sorted; default to non-verbose.
- `face_triangulations` moved into the `ntfe` subpackage.

### Fixed

- Broken cache files are now cleared automatically.
- Import bugfixes in the NTFE code.

## [1.4.4] - 2025-10-17

### Changed

- Dependencies updated (`numba`, `qpsolvers`) to allow for modern Python;
  `numpy` constrained to work better with `numba`.
- Heights are copied to and from Kähler parameters.
- Charges are always returned as at least a list.

### Fixed

- NTFE bugfix (removed an outdated argument).

## [1.4.3] - 2025-09-08

### Added

- `is_trilayer` check.
- NTFE cones can be constructed without checks.

### Changed

- `fetch_polytopes` defaults to `as_list=True` and to the N lattice.
- Cleaned dense representation of NTFE cones; dense representations default
  to unique rows.
- Python version pinned to 3.12 (3.13 broke `qpsolvers`).

### Fixed

- Bugfixes for constructing 5d polytopes, for 1D cones, and for facets of

## [1.4.2] - 2025-08-13

### Added

- Methods to convert hyperplanes to dense and 64-bit representations.
- `mori_cone_cap` verbosity.

### Changed

- Heights are reduced by their GCD only when nonzero (the warning for zero
  heights was removed).
- Dependencies: `sympy` removed; `mosek`, `ipywidgets` and `anywidget` added.

## [1.4.1] - 2025-08-06

### Added

- `is_degenerate` method for cones.

### Changed

- Some outputs converted from NumPy typing to Python typing.
- `extremal_rays` for cones now uses the LP backend rather than NNLS, roughly
  35% faster; cleaner `is_pointed` method.
- Star constraints in the NTFE submodule clarified/improved.
- 16-bit hyperplane matrices and corrected homogenization for star
  triangulations.

## [1.4.0] - 2025-07-31

Primary change: CYTools is now installed via pip rather than Docker.

### Added

- Conda environment files (`environment.yml`, `environment-dev.yml`) and CI
  testing on Linux arm64.
- Lineality space computations for cones, including decomposition of a cone
  into its lineality space plus its pointed part; integral nullspace helper
  in `utils`.
- Lower bound on `find_interior_point`.

### Changed

- Cone improvements: facet computation, simplicial checking, dimension.
- Parallelism moved from `multiprocessing` to `joblib` (faster and more
  resilient across operating systems).
- Fine triangulations produced with TOPCOM.
- `flint` used instead of `sympy` in parts of the code.
- Extremal ray computation sped up and simplified.

### Removed

- `sympy` dependency.

## [1.1.0] - 2024-02-19

Marked as a minor version primarily because of the points-by-labels change
introduced in 1.0.14.

### Added

- Access to vertex labels, with labels generated when they do not exist.
- `extremal_hyperplane` function.
- Additional verbosity in several places.

### Changed

- Vertices are sorted lexicographically by their original representation.
- Several memory optimizations: heights stored as integers, caches excluded
  from pickling, caching keyed by function name, and additional caching of
  triangulation optimal points.
- `random_triangulations_fast` enabled for non-full-dimensional
  configurations; star triangulations allowed even when the origin is not the
  0th point.
- Backends specified more explicitly; feasibility check separated out.

### Fixed

- Various label-related bugfixes.

## [0.8.0] - 2022-10-27

### Added

- `simplices` accepts `on_faces_dim` / `on_faces_codim` to return the
  simplices on faces of the given (co)dimension.
- `Triangulation.automorphism_orbit` computes the orbit under polytope
  automorphisms, and `Triangulation.is_equivalent` checks equivalence (with
  automorphisms by default; also accepts `on_faces_dim` / `on_faces_codim`).
- `Triangulation.heights` returns a height vector generating the
  triangulation.
- `Cone.find_interior_point` finds a point in the strict interior, optionally
  integral, using OR-Tools unless `d >= 25` and Mosek is activated.
- `Cone.find_grading_vector` finds a grading vector for a pointed cone.
- `Cone.find_lattice_points`, optionally with a filter function or with
  streaming processing instead of building a full list.
- Support for triangulations of point configurations that are not
  full-dimensional; triangulation of polytopes of arbitrary dimension with
  CGAL; option to find all triangulations without constructing `Triangulation`
  objects; seeds for the random triangulation generators.
- Config option to limit the number of threads.
- Unit tests, runnable with `make test`.

### Changed

- `CalabiYau` checks trivial equivalence via `Triangulation.is_equivalent`
  (with automorphisms, restricted to codimension-2 faces).
- `tip_of_stretched_cone` uses OR-Tools for an approximation when `d >= 25`
  (unless Mosek is activated) and OSQP below that, which is faster than Mosek.
- Faster regularity checking makes several other computations, such as
  enumerating all triangulations, faster as well.

### Fixed

- A couple of triangulation bugs and various other small issues.

Breaking change: the `CalabiYau` hash changed again, so sets of CYs will
disagree in ordering with ones built by earlier versions.

recommended for use other than testing.

  generators, `fetch_polytopes`/`read_polytopes` with an `as_list` option,
  and an update checker.
