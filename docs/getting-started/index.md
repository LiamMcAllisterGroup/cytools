# Get started

CYTools is an open-source Python package that relies on various other software
packages built for Unix-like systems. It can be installed with pip, but we
recommend installing it in a conda environment, which includes all optional
dependencies and some useful tools such as JupyterLab.

We provide simple installation and usage instructions for the major operating
systems. They are meant for most users, as they allow you to install and use
CYTools without having to memorize long commands.

<div class="cy-buttons" markdown>
[Linux/macOS](linuxmacos.md){ .md-button .md-button--primary }
[Windows](windows.md){ .md-button .md-button--primary }
</div>

Once you are done with the installation, we encourage new users, especially
those who are not familiar with Python, to follow the tutorial, where we
showcase the most important functionality and give concrete examples of common
computations one might be interested in.
